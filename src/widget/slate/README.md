# Widgets de Slate

> Mots-clés :
> [_gout_](https://github.com/search?q=_gout_+language%3AMarkdown&type=Code&l=Markdown),
> [_gout-widget_](https://github.com/search?q=_gout-widget_+language%3AMarkdown&type=Code&l=Markdown),
> [_gout-widget-slate_](https://github.com/search?q=_gout-widget-slate_+language%3AMarkdown&type=Code&l=Markdown).

Ce répertoire regroupe des widgets pour les flux RSS du site
[**Slate**](https://www.slate.fr/). Pour ajouter un widget dans votre dashboard,
insérez le code suivant :

```html
<script
  type="application/yaml"
  src="https://cdn.jsdelivr.net/gh/regseb/gout-regseb@0/src/widget/slate/slate.yaml"
></script>
```
